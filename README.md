# Sneh M. Malani — Portfolio website

Professional portfolio for companies and individuals to review work experience and get in touch.

This is a static website. It does not need a paid server. GitHub Pages hosts it for free.

## Preview on your computer

1. Open the folder `Portfolio website`.
2. Double-click `index.html`.
3. It should open in your browser.

## Publish on GitHub (shareable link)

You need a free GitHub account: https://github.com/signup

1. Open https://github.com/new
2. Repository name suggestion: `sneh-malani-portfolio`
3. Keep it **Public** (required for free GitHub Pages on a normal account).
4. Do not add a README on GitHub (this folder already has one).
5. Click **Create repository**.
6. On the next page, upload these files:
   - Click **uploading an existing file**
   - Drag every file and folder from this project into the page (`index.html`, `css`, `js`, `assets`, `404.html`, `.nojekyll`, `README.md`)
   - Click **Commit changes**
7. Open the repository **Settings** → **Pages**
8. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (or **master**), folder **/ (root)**
   - Save
9. After 1–2 minutes, GitHub shows a URL like:

`https://YOUR-USERNAME.github.io/sneh-malani-portfolio/`

Share that URL.

If you prefer, install GitHub Desktop and publish this folder as a repository, then follow steps 7–9.

## What is on the site

- Professional summary
- Full work history from the latest resume
- Product areas
- Skills, education, awards
- Contact: email, phone, LinkedIn, and a message form that opens the visitor’s email app

## Security notes (honest)

This site includes extra protections:

- No server, no database, no passwords, no hidden keys
- Contact form never stores messages on a website
- Content Security Policy (browser is told not to load unknown scripts)
- Right-click, view-source shortcuts, save, print, and common developer-tool shortcuts are blocked in the page
- Print/PDF output is blanked

These are **deterrents**, not a lock. A public website cannot fully stop:

- Screenshots from the operating system (for example Mac screenshot keys)
- Developer tools opened in another way
- Copying text that is already visible on screen

That is a browser/OS limit, not something a portfolio site can truly enforce.

## Update the site later

Edit the files in this folder, then upload the changed files to the same GitHub repository (or ask for help). GitHub Pages will refresh the live link.
